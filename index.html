Import real match stats

Upload one or more Ballchasing replay-detail JSON files. Each replay is stored locally in this browser and duplicates are ignored. You can also upload a JSON array of replay-detail objects.

Don't paste your Ballchasing API token into this website. It is a static site, and secrets must be handled by a secure backend or local script.

How to use EADC

1. Publish this site for free using Cloudflare Pages Direct Upload.

2. Upload your Casual 3v3 replays to Ballchasing.

3. Export replay-detail JSON using the included PC sync script, then import it into EADC.

4. For fully shared, hands-free live stats, a secure scheduled backend and shared database are the next phase. This first version saves data in the current browser only.

Player identity is matched using Steam IDs, not display names.
