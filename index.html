Import real match stats

Upload Ballchasing replay-detail JSON files or an array of replay details. Duplicates are ignored. The scheduled GitHub sync also loads stats.json automatically.

Never paste your Ballchasing API token into this website.

EADC setup

EADC loads stats.json from this GitHub Pages site after the scheduled Ballchasing sync. You can also import replay-detail JSON manually in the Import Stats tab.

Player identity is matched by replay player IDs, not display names. Only matches containing all three configured players on the same team are counted.

Automatic replay uploading from your PC still needs to be connected to Ballchasing.
